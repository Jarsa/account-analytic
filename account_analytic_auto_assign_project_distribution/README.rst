Adds a **Project Distribution** to the analytic account, to split a
project between other analytic plans (for example 60% branch A and 40%
branch B).

When that account is set as the project of an invoice, sale order or
purchase order (see ``account_analytic_auto_assign_account_move``), its
lines get that split, with the project in every row. The split replaces
the plans it touches; the other columns given by the analytic
distribution models are kept.

Usage
=====

1. Open the analytic account of a project and fill **Project
   Distribution**, for example 60% branch A and 40% branch B.
2. Set that project on an invoice: every product line gets
   ``project + branch A`` at 60% and ``project + branch B`` at 40%.
