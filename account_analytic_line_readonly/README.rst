======================
Analytic Line Readonly
======================

This module sets the analytic line form view as read-only, including the
dynamic analytic plan columns, so analytic items can only be reviewed but
not modified from the form view.

**Table of contents**

.. contents::
   :local:

Usage
=====

Install the module. All fields of the analytic item form view
(*Accounting > Analytic Items*) become read-only, including the analytic
plan fields generated dynamically.
